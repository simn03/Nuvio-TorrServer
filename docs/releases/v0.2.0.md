Stability release: fixes the broken image build, patches all known vulnerabilities, fixes a crash on some searches, and adds a tag-based release flow.

## Fixes

- **Crash on some searches:** release titles starting with a bracketed tag (e.g. `[1080p] The Shawshank Redemption`) crashed the title parser and returned HTTP 500 for the whole stream list. Those titles are now treated as unparsed.
- **Broken image build:** upstream deleted the pinned TorrServer release, so the image could not be built. It is now pinned to a release that persists and checked against its SHA-256.
- **Security:** patched GO-2026-5775 and GO-2026-5777 (`go-chi/chi` v5.1.0 → v5.5.0); Go 1.23 → 1.26 (all standard-library fixes); Alpine 3.20 (EOL) → 3.24; all Go modules on their latest versions.

## Project / CI

- PRs now run vet, race tests, a vulnerability scan, and an image build with a smoke test.
- Releases come from `vX.Y.Z` tags: multi-arch (amd64 + arm64) images, signed build-provenance attestations, and GitHub Releases.
- Dependabot keeps Go modules, Docker base images and GitHub Actions up to date.
- The manifest version now matches the release tag.
