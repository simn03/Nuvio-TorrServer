Stability release: fixes the broken image build, patches all known vulnerabilities, fixes a crash on some searches, and adds a tag-based release flow.

> [!CAUTION]
> ## ⚠️ Breaking changes — read before upgrading
>
> ### 1. The image has a new name
> Images are now published as **`ghcr.io/simn03/nuvio-torrserver`**. The old
> `ghcr.io/simn03/nuvio-p2p-http-addon` image **no longer receives updates**,
> including security fixes. Nothing warns you if you stay on it.
>
> ```diff
> -    image: ghcr.io/simn03/nuvio-p2p-http-addon:latest
> +    image: ghcr.io/simn03/nuvio-torrserver:0.2.0
> ```
>
> ### 2. TorrServer upgraded: MatriX.142.1 → MatriX.147
> TorrServer may migrate its config/database in `/data/torrserver` on first
> start. **Back up the `/data/torrserver` volume before upgrading** if you might
> want to roll back to an older image.
>
> ### 3. Custom `TS_VERSION` builds now need checksums
> The TorrServer binary is now verified with SHA-256. If you build with
> `--build-arg TS_VERSION=...`, you must also pass the matching
> `TS_SHA256_AMD64` / `TS_SHA256_ARM64` / `TS_SHA256_ARM7`, or the build fails.
> Use base tags (`MatriX.NNN`), not point releases: upstream deletes those.
> Building for any architecture other than amd64, arm64 or 32-bit arm now fails
> with a clear error.
>
> ### 4. Building from source needs Go 1.26+
> The module now targets Go 1.26. Go 1.23 is no longer supported.
>
> ### 5. The repository was renamed to `simn03/Nuvio-TorrServer`
> GitHub redirects the old URLs, but update any clone URLs and raw-file links
> (`.env.example`, `docker-compose.example.yml`) in scripts.

## Upgrading

1. Back up your volumes (at least `/data/torrserver`; `/data/addon` holds users and settings).
2. Change `image:` to `ghcr.io/simn03/nuvio-torrserver:0.2.0` (or `:0.2` for patch updates).
3. `docker compose pull && docker compose up -d`, then check the logs show
   `TorrServer MatriX.147` and the container reaches `healthy`.

No addon database migrations and no `.env` changes are required, and existing install URLs keep working.

## Fixes

- **Crash on some searches:** release titles starting with a bracketed tag (e.g. `[1080p] The Shawshank Redemption`) crashed the title parser and returned HTTP 500 for the whole stream list. Those titles are now treated as unparsed.
- **Broken image build:** upstream deleted the pinned TorrServer release, so the image could not be built. It is now pinned to a release that persists and checked against its SHA-256.
- **Security:** patched GO-2026-5775 and GO-2026-5777 (`go-chi/chi` v5.1.0 → v5.5.0); Go 1.23 → 1.26 (all standard-library fixes); Alpine 3.20 (EOL) → 3.24; all Go modules on their latest versions.

## Project / CI

- PRs now run vet, race tests, a vulnerability scan, and an image build with a smoke test.
- Releases come from `vX.Y.Z` tags: multi-arch (amd64 + arm64) images, signed build-provenance attestations, and GitHub Releases.
- Dependabot keeps Go modules, Docker base images and GitHub Actions up to date.
- The manifest version now matches the release tag.
