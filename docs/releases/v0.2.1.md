Bug-fix release with no new breaking changes since 0.2.0. Coming from 0.2.0, change the image tag to `0.2.1` (or pull `:0.2` / `:latest`). Coming from 0.1.x, read the breaking changes above first.

## Fixes

- **"Source Error … error_code_parsing_container_unsupported" on some streams.** Some new-episode torrents are fakes: the release name looks real (e.g. `Show S01E07 1080p WEB H264-GROUP`), but the torrent's only file is a Windows `.exe`. The addon streamed file 1 without checking its type, so the player received an executable instead of video. Now:
  - `/play` checks the torrent's file list and refuses a torrent with no video file (HTTP 415) instead of proxying it.
  - Torrents found this way are remembered and **dropped from later stream lists**. When `TORRSERVER_PRELOAD=true`, the top result is also checked in the background, so a fake there is often gone before anyone presses play.
- **Wrong file streamed when file 1 isn't the video.** If a torrent lists subtitles, an `.nfo` or other extras before the video, `/play` now streams the largest video file instead of file 1.
